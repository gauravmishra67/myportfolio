# Gaurav Kumar Mishra — Personal Portfolio

A modern, interactive personal portfolio website built to showcase my projects, skills, experience, and creative work as an aspiring engineer and UI/UX designer.

The website combines a clean monochrome interface with interactive 3D elements and smooth animations to create an immersive browsing experience.

## ✨ Features

- 🎨 Modern and minimal UI/UX
- 🧊 Interactive 3D hero section with Three.js
- ⚡ Smooth animations and transitions
- 📱 Fully responsive design
- 💼 Projects showcase
- 🛠️ Skills and technologies section
- 👤 About Me section
- 🎯 Goals section
- 📄 Resume section
- 📬 Contact section
- 🌐 Social and professional links
- 🚀 Optimized Vite production build

## 🛠️ Tech Stack

### Frontend

- React 19
- TypeScript
- Vite
- Tailwind CSS

### 3D & Animation

- Three.js
- React Three Fiber
- React Three Drei
- Framer Motion

### Utilities

- clsx
- tailwind-merge

## 🎨 Design

The portfolio follows a clean monochrome visual direction with a focus on:

- Strong visual hierarchy
- Minimal and modern layouts
- Interactive 3D elements
- Smooth micro-interactions
- Responsive design
- Accessibility and readability

The 3D hero experience is built using React Three Fiber and Three.js.
